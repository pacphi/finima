### A1 — Same workspace rebuilt 3× under different profiles, serially

- **severity:** high
- **evidence:** .github/workflows/ci.yml:48 (`cargo clippy --workspace --all-targets`),
  .github/workflows/ci.yml:76 (`cargo test --workspace`, `needs: backend-lint`),
  .github/workflows/ci.yml:222 (`cargo build --release -p finima-api`, e2e job)
- **deliverable:** A single build-once step — `cargo nextest archive` for the debug/test profile,
  consumed by `backend-test` (and `llm-test` when enabled) instead of each job invoking `cargo test`
  from scratch. The release build for e2e stays separate (different profile) but should share
  `Swatinem/rust-cache` state explicitly keyed so it isn't a cold rebuild every run.
- **definition_of_done:**
  - grep: nextest archive in .github/workflows/**
  - grep: archive-file in .github/workflows/**
- **validation:** CI green; `backend-test` no longer runs `cargo build`/`cargo test` from scratch —
  confirm via job log timing (archive-consume step should be seconds, not full compile).
- **est_impact:** deterministic: full-workspace-compiles-per-PR 3 → 2 (clippy + release build remain
  distinct profiles; test moves to archive-consume). empirical: warm time-to-green improvement TBD
  over ≥5 runs post-fix (baseline: 198s median, n=22).
- **risk:** low
- **depends_on:** []

- **deliverable:** For each hit: remove if genuinely unused, or add to

  machete has known false positives, especially for macro-derived or re-exported usage; several of
  these (e.g. `finima-core` in `finima-llm`, `tracing` in two crates) look like plausible false
  positives worth checking by hand before removal, not blind deletions.
- **definition_of_done:**
  - cmd: cargo machete
  - cmd: cargo build --workspace
  - cmd: cargo test --workspace
- **validation:** `cargo build --workspace` and `cargo test --workspace` both exit 0 after each
  removal; re-run `cargo machete` to confirm the hit list shrinks (or is explicitly ignored with
  rationale).
- **est_impact:** deterministic: 13 machete hits → 0 (removed or documented-ignored). Secondary:
  `Cargo.lock` line count (currently 10,479 lines / 950 packages) may shrink if any removed crate
  drops transitive deps nothing else pulls in.
